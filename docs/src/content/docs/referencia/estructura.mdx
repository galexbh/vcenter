## Elementos que no se versionan

| Ruta o patrón | Motivo |
|---|---|
| `reports/`, `reporte-*.html`, `reporte-*.md`, `*.raw.json` | Inventario interno |
| `logs/` | Bitácora de auditoría con usuarios y comandos |
| `config/environments.json` | Nombres de servidores internos |
| `specs/*` (salvo `specs/.gitkeep`) | Datos de provisión (direcciones IP, nombres) |
| `tools/` | Binarios descargados |
| `*.env`, `.env*`, `*.pem`, `*.pfx`, `*.key`, `.govmomi/` | Secretos y certificados |
| `.claude/settings.local.json` | Configuración local de Claude Code de cada persona |

## Elementos protegidos frente a Claude

| Ruta o comando | Control |
|---|---|
| `scripts/lib/**` (incluido `Common.psm1`), `.claude/hooks/**`, `.claude/settings.json` | Modificación bloqueada |
| `scripts/govc.ps1`, `config/environments.json`, `.claude/skills/**`, `.claude/commands/**`, `.githooks/**` | Modificación con aprobación |
| Scripts de reportes con `-OutDir` | Ejecución con aprobación |
| `logs/**` | Escritura, movimiento y eliminación bloqueados |
| `~/.govmomi/**` | Lectura bloqueada |
| `cmdkey` (cualquier uso, en PowerShell y Bash), `Set-GovcCredential.ps1` | Ejecución bloqueada: la credencial la registra una persona |
| `git add -f`, `git add --force` | Ejecución bloqueada |
