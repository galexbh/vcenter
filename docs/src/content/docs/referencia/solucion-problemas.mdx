| Síntoma | Causa probable | Acción |
|---|---|---|
| `No existe config/environments.json` | Perfil no creado | Ejecutar `task setup` (o copiar `environments.example.json`) y completarlo |
| `Entorno 'x' no definido` | Nombre incorrecto o perfil ausente | Revisar las claves del archivo (en minúsculas) |
| `No hay credencial 'govc:x'` | Credencial no registrada, o registrada con otro destino | Comprobar con `task credential:list` y registrarla con `task credential ENV=x` (o `./scripts/Set-GovcCredential.ps1 -Env x`) en una terminal propia, fuera de Claude Code |
| `NotAuthenticated` / `InvalidLogin` | Contraseña vencida o rotada | Registrar nuevamente la credencial |
| `x509: certificate signed by unknown authority` | Falta la autoridad certificadora interna, o vCenter renovó o reemplazó su CA | Configurar o actualizar `caCerts` (ver [certificados de la CA](/vcenter/inicio/configuracion/#certificados-de-la-ca-cacerts)); no habilitar `insecure` en producción |
| `NoPermission` | La cuenta de servicio carece del privilegio | Solicitar el privilegio específico; no utilizar otra cuenta |
| `resolves to multiple instances, please specify` | Existen varios pools, datastores u hosts posibles | Indicar `-pool`, `-ds` o `-host`, o definirlos en el perfil |
| `InvalidPowerState` al convertir en plantilla | La VM está encendida | El apagado es destructivo: en producción lo ejecuta una persona |
| `find` sin resultados | Otro datacenter o ruta relativa | Utilizar una ruta absoluta o `-dc` |
| `[govc-guard] … destructivo fuera de lab` | Política del entorno | Ejecutar en una terminal propia con cambio aprobado |
| `[govc-guard] No ejecutes govc directamente` | Invocación de `govc` o `tools/govc.exe` | Utilizar `./scripts/govc.ps1 -Env …` |
| `[govc-guard] El contenido accede a Credential Manager` | Claude intentó escribir código que accede a la bóveda | Comportamiento esperado; cualquier cambio en ese ámbito lo revisa una persona |
| `[govc-guard] logs/ es la bitácora de auditoría` | Intento de modificar o eliminar la bitácora | Comportamiento esperado; la gestión de la bitácora corresponde a una persona |
| Claude solicita aprobación para una lectura | El comando combina otros cmdlets, redirecciones o variables | Comportamiento esperado; aprobar o simplificar el comando |
| `Test-AuditLog.ps1` informa una ruptura | Registro editado, eliminado o insertado | Preservar la evidencia e informar a Seguridad de la Información |
| `[govc-guard] La carpeta de sesion efimera de govc (o las sesiones guardadas de govmomi) …` | Claude intentó leer, listar o buscar en la carpeta de sesión del modo lote o en las sesiones guardadas de govmomi (`read-guard.sh`) | Comportamiento esperado; la sesión activa no se lee desde Claude |
| `govc no encontrado` | govc no instalado | Ejecutar `task install` (o `./scripts/Install-Govc.ps1`) |
| `pre-commit: archivos que no deben versionarse` | Se incorporó un reporte o una bitácora | `git restore --staged <archivo>` |
| `pre-commit: el diff parece contener credenciales` | El contenido agregado incluye una contraseña o una URL con usuario y contraseña | Retirar el secreto del archivo, registrarlo en Credential Manager y, si llegó a compartirse, rotarlo |
| `task` no se reconoce como comando | Task no instalado o terminal abierta antes de instalarlo | `winget install --id Task.Task -e` y abrir una terminal nueva |
| `Indica ENV=<entorno> o FROM=<carpeta en reports/>` | Tarea de reporte, revisión de hosts o auditoría sin origen de datos | Indicar `ENV=` o `FROM=` |
| `SCOPE admite full, security o capacity` | Valor de `SCOPE` no válido en `task audit` | Corregir el valor u omitirlo |
| `La credencial la registra una persona en su propia terminal, no Claude.` | `task credential` se ejecutó dentro de Claude Code (incluido el prefijo `!`) | Ejecutarla en una terminal propia, fuera de Claude Code |
| `Las credenciales las consulta una persona en su propia terminal, no Claude.` / `La credencial la elimina una persona en su propia terminal, no Claude.` | `task credential:list` o `task credential:remove` se ejecutó dentro de Claude Code | Ejecutarla en una terminal propia, fuera de Claude Code |
| `task: Task "credential:remove" cancelled by user` | Se respondió que no a la confirmación | Comportamiento esperado; la credencial no se modificó |
| `vcsim no está instalado: task install -- -WithVcsim` | `task vcsim` sin el simulador en `tools/` | `task install -- -WithVcsim` |

## Pruebas con el simulador

```powershell
task install -- -WithVcsim
task vcsim
```

`task vcsim` mantiene el simulador en ejecución; los comandos siguientes se ejecutan en otra terminal.

Agregar un perfil de prueba y su credencial (usuario `user`, contraseña `pass` del simulador):

```json
"vcsim": { "url": "https://127.0.0.1:8989/sdk", "mode": "lab", "datacenter": "DC0", "insecure": true }
```

```powershell
task credential ENV=vcsim ACCOUNT=user
./scripts/New-Report.ps1 -Env vcsim
```
