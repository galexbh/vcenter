## govc.ps1

```powershell
./scripts/govc.ps1 -Env <entorno> <subcomando> [args]
```

```powershell
./scripts/govc.ps1 -Env <entorno> -Batch <archivo.json>   # lote de lecturas, una sesión
```

Ver [Wrapper govc.ps1](/vcenter/uso/wrapper/).

## New-Report.ps1

| Parámetro | Tipo | Valor por defecto | Descripción |
|---|---|---|---|
| `-Env` | string | — | Entorno (obligatorio si no se usa `-FromRaw`) |
| `-Type` | `all` `inventory` `snapshots` `capacity` `health` | `all` | Secciones del reporte |
| `-Format` | `html`, `md`, `csv` | `html`, `md` | Formatos de salida (`csv`: un archivo por tabla) |
| `-CsvDelimiter` | string | separador regional de Windows | Separador de los archivos CSV |
| `-FromRaw` | ruta | — | Recalcula desde una corrida existente |
| `-OutDir` | ruta | `reports/<env>/<marca>` | Carpeta de salida (la usa `Invoke-Audit.ps1`) |
| `-SnapshotWarnDays` / `-SnapshotCritDays` | int | 7 / 30 | |
| `-DatastoreWarnPct` / `-DatastoreCritPct` | int | 80 / 90 | |
| `-VcpuRatioWarn` / `-VcpuRatioCrit` | double | 4 / 6 | |
| `-MemRatioWarn` | double | 1,0 | |
| `-HostMemWarnPct` | int | 85 | |
| `-MinHwVersion` | int | 14 | |
| `-CertWarnDays` / `-LicenseWarnDays` | int | 60 / 60 | |
| `-SkipDeviceScan` | switch | — | Omite la detección de ISO conectada. Recomendado con miles de VMs (con 5000 VMs reduce el volumen de ~65 MB a ~6 MB y ~1 GB de memoria). Se informa como limitación de cobertura |
| `-MdMaxRows` | int | 200 | |

## Invoke-Audit.ps1

| Parámetro | Tipo | Valor por defecto | Descripción |
|---|---|---|---|
| `-Env` | string | — | Entorno (obligatorio si no se usa `-FromRaw`) |
| `-Cluster` | string[] | todos | Limita la revisión de hosts |
| `-Scope` | `full` `security` `capacity` | `full` | Dominios evaluados |
| `-Format` | `html`, `md` | ambos | |
| `-FromRaw` | ruta | — | Regenera el informe desde una auditoría existente |
| `-MaxRootAdmins` | int | 5 | Umbral de principales con rol Administrador en la raíz |
| `-SkipDeviceScan` | switch | — | Se transmite a `New-Report.ps1` |
| `-Version` | string | `1.0` | Versión del documento |

## Test-Guards.ps1, Test-Reports.ps1 y Test-AuditLog.ps1

| Script | Función | Salida |
|---|---|---|
| `Test-Reports.ps1 [-Keep]` | Pruebas de regresión de reportes, CSV, hosts, auditoría y tendencias (ver [Pruebas](/vcenter/referencia/pruebas/)) | Código de salida igual al número de fallas |
| `Test-Guards.ps1` | Pruebas del clasificador y del hook | Código de salida igual al número de fallas |
| `Test-AuditLog.ps1 [-Path]` | Verificación de la cadena de hashes de la bitácora | `0` si está íntegra; `1` e indicación de la línea si no |

## Set-GovcCredential.ps1

| Parámetro | Descripción |
|---|---|
| `-Env` | Entorno (utiliza su `credentialTarget` o `govc:<env>`) |
| `-UserName` | Opcional; si se omite, se solicita |
| `-Remove` | Elimina la credencial |

Rechaza su ejecución cuando lo invoca Claude.
