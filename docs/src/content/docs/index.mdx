## Capacidades

<CardGrid stagger>
	<Card title="Seguridad por diseño" icon="seti:lock">
		Un único punto de acceso lee la credencial en cada operación, la expone solo durante la ejecución y registra cada acción en una bitácora con integridad verificable.
	</Card>
	<Card title="Consulta eficiente" icon="rocket">
		El inventario completo se obtiene con un número fijo de consultas en bloque, independiente del tamaño del entorno.
	</Card>
	<Card title="Auditoría formal" icon="document">
		Informe imprimible con resumen ejecutivo, metodología, hallazgos identificados, plan de remediación y sección de aprobación.
	</Card>
	<Card title="Cambios controlados" icon="approve-check">

	</Card>
</CardGrid>

## Comandos principales

| Comando | Propósito |
|---|---|
| `/env prod` | Verificar perfiles y conectividad |
| `/inventory prod` | Resumen de inventario en pantalla |
| `/health prod` | Hallazgos priorizados con acciones sugeridas |
| `/capacity prod` | Capacidad por clúster y holgura ante falla de un host |
| `/host-check prod CL-PROD-01` | Revisión de configuración de hosts y detección de diferencias |
| `/audit prod` | Auditoría técnica completa con informe formal |
| `/trend prod` | Tendencias entre las dos últimas corridas |
| `/vm-create specs/app01.yaml` | Provisión de una VM con validación y aprobación |
