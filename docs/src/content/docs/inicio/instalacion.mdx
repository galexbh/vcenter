## Requisitos

| Requisito | Detalle |
|---|---|
| Windows 10/11 | Windows Credential Manager actúa como bóveda de credenciales |
| PowerShell 7.5 o superior (`pwsh`) | Necesario para `ConvertFrom-Json -DateKind` y para el analizador de comandos del hook |
| Git for Windows | Ejecuta el control `pre-commit` |
| Claude Code | CLI, aplicación de escritorio o extensión de IDE |
| [Task](https://taskfile.dev) (opcional) | Atajos de `Taskfile.yml`. Instalación: `winget install Task.Task` |
| Node.js 20 o superior | Solo para compilar esta documentación |
| Cuenta de servicio de vCenter | Una por entorno, con el **rol mínimo** necesario |

## Procedimiento

<Steps>

1. **Instalar govc** en `tools/` (excluido de git):

   ```powershell
   ./scripts/Install-Govc.ps1
   ```

   El script descarga `govc_Windows_x86_64.zip` de la versión estable más alta disponible desde las publicaciones oficiales de [vmware/govmomi](https://github.com/vmware/govmomi/releases), verifica su SHA-256 contra el archivo `checksums.txt` de la misma publicación y copia `govc.exe` a `tools/`. Para instalar una versión concreta: `-Version v0.56.0`.

2. **Opcional: instalar el simulador** para pruebas sin un vCenter real:

   ```powershell
   ./scripts/Install-Govc.ps1 -WithVcsim
   ```

3. **Activar el control de git** que impide versionar reportes, bitácoras y credenciales:

   ```powershell
   git init
   git config core.hooksPath .githooks
   ```

4. **Verificar las guardas:**

   ```powershell
   ./scripts/Test-Guards.ps1
   ```

   Todas las pruebas deben finalizar sin fallas.

</Steps>

:::tip[Actualización de govc]
Para actualizar, volver a ejecutar `./scripts/Install-Govc.ps1`. Se elige la versión semántica más alta entre las publicaciones estables, no la marcada como *latest* en GitHub: govmomi publica parches de ramas anteriores (por ejemplo, `v0.55.2` después de `v0.56.0`) y esa marca apunta a la más reciente. Si una versión nueva presenta problemas, fijar la anterior con `-Version`.
:::
